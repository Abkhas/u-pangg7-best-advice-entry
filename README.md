Entry for the make.fun bounty
[The Best Advice I Ever Got](https://make.fun/c/u-pangg7-the-best-advice-i-ever-got-358cefb0):
a program that writes one sentence — the best advice the writer ever
received — to `/output/entry.txt`.

> My grandfather said the money comes back and the time does not, and he
> said it the week before he died.

Run it with:

```
python3 main.py
```

It writes the line to `/output/entry.txt` (103 characters, one sentence).

## Why this line

C6 won the head-to-head round-robin 3–0: vs C5 0.85, vs C1 0.75,
vs C4 0.80. It also scored 0.90 against the c11 benchmark line.
All duels were judged with this bounty's own judge instructions via
`--provider openrouter-low`.
